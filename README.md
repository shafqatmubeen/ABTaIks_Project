# ABTalks — 60-Day Coding Challenge

A modern, premium, mobile-first redesign of the **ABTalks 60-Day Coding Challenge**.

ABTalks helps college students build coding consistency by completing a project every day for 60 days and submitting proof of their work through **GitHub and LinkedIn**.

## ✨ Features

* Premium mobile-first interface optimized for 390px
* Engaging landing page explaining the 60-day challenge
* Student dashboard with streak, progress, achievements, and today's task
* Complete daily challenge experience
* GitHub and LinkedIn proof-of-work submission
* "Next Best Action" feature to guide students
* First-day, missed-day, and empty-profile states
* Smooth page transitions, scroll animations, micro-interactions, and loading screen
* Responsive design for mobile, tablet, and desktop

## 🎨 Design

The interface uses a dark premium visual system with purple, mint, and yellow accents.

The design focuses on:

* Clear visual hierarchy
* Student motivation
* Progress visibility
* Simple navigation
* Smooth and purposeful animations
* Comfortable mobile interaction

## 🛠️ Tech Stack

* React
* Vite
* Tailwind CSS
* Framer Motion
* JavaScript
* Mocked data

Authentication and a production database are intentionally out of scope for this hackathon.
